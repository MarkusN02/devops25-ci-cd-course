# devops25-ci-cd-course

Min fork av kursrepot i CI/CD (Nackademin, DevOps Engineer).

## Dag 1 - Git-övning

I den här övningen har jag arbetat med Git och Github:

- Forkat kursens repository till mitt eget GitHub-konto och klonat det till min dator.
- Kontrollerat att `origin` pekar på min egen fork med `git remote -v.
- Skapat en egen branch (`demo/dag1-markus`) i stället för att ändra direkt i `main`.
- Gjort en änding i `README.md` och granskat den med `git status`.
- Sparat ändringen med `git add` och `git commit`.
- Publicerat branchen med `git push` och öppnat en Pull Request mot `main` i min egen fork.

Jag har lärt mig skillnaden mellan commit (sparar lokalt) och push (skickar till GitHub), och att en Pull Request är ett förslag på ändring som kan grankas innan den slås ihop.
